---
title: "Репост: T3 Code оркестрирует задачи по всем подключённым машинам"
---

Своего текста у Theo нет, это репост Luis Kisters. Luis пишет, что T3 Code теперь умеет нативно оркестрировать работу по всем подключённым удалённым машинам. Можно сказать что-то вроде «собери iOS/Mac-часть на моих Linux-машинах, а тесты запусти на маках», и он называет это переломным моментом для себя. По его словам, у других ADE (agentic development environment — сред разработки с агентами) нет даже равных возможностей.

В посте ссылка на пост Theo (x.com/theo/status/2115398275385921844), но открыть её не удалось: X требует авторизацию. Судя по соседним постам, это то же мульти-машинное демо, которое Julius неделю обкатывал внутри команды.
