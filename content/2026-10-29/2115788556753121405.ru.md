---
title: "Как он будит тред Codex, застрявший из-за падения провайдера"
---

Пользователь T3 Code пожаловался: провайдер упал из-за нехватки мощностей, тред простоял шесть часов, пока он спал. Он просит, чтобы T3 Code сам пинговал провайдера через интервалы, пока тот не оживёт.

Theo отвечает двумя вещами. Во-первых, сам Codex, насколько он знает, так не делает. Во-вторых, он не хочет устраивать OpenAI thundering herd. Так называют ситуацию, когда тысячи клиентов одновременно повторяют запросы к упавшему сервису и мешают ему подняться. Поэтому автоповтора в T3 Code он не обещает.

Для себя у него есть ручной обход:
1. Завести отдельный тред на Haiku (самая дешёвая модель Claude).
2. Запускать его по расписанию раз в 15 минут.
3. Задача этого треда: проверить тред Codex и «подтолкнуть» его, если он стоит.

Через что именно он ставит расписание, в посте не сказано. В T3 Code есть запланированные задачи, так что, вероятно, через них, но это моя догадка.
