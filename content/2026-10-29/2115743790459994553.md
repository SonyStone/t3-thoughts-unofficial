Theo praises a T3 Code feature shipped by Julius (@jullerino, a T3 Code developer): secure secret passing to agents. In his words, it's "absurdly convenient".

The screenshot shows an agent on Opus 5.5 setting up a test environment for PR #26757 and asking Theo for a Tailscale auth key. A separate "Asking for a secret" card appears in the chat. In it the agent explains which key it needs, where to create it, and which options to turn on: reusable, ephemeral, pre-approved, expiring after one day. Below that are an input field and the buttons "Save securely" and "Decline".

The text under the field says the secret doesn't go into the chat. It's kept in a private file that this agent's commands can read for 24 hours.

The convenience is that the key doesn't stay in the thread history or the model's context, and you don't have to paste it into the chat in plain text. That's my conclusion from the screenshot, Theo only talks about convenience. The same day Julius wrote that the feature went in a while back and was never specially announced.
