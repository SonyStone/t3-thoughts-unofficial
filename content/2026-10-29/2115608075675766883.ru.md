---
title: "Модели Antigravity: только то, что отдаёт ACP"
---

Jake Paterson просит добавить в T3 Code модели Claude и ChatGPT из Google Antigravity. На первом скриншоте провайдер Antigravity в настройках T3 Code показывает только Gemini 4 Argon и Gemini 3.8 Flash. На втором — квоты аккаунта Antigravity, в том числе общая квота «Claude & GPT». То есть подписка даёт доступ к этим моделям, а в T3 Code их нет.

Theo отвечает, что T3 Code показывает то, что Antigravity отдаёт по ACP, и сделать с этим они почти ничего не могут. ACP (Agent Client Protocol) — открытый протокол, по которому редакторы и оболочки общаются с кодинг-агентами. Если Antigravity не публикует модели Claude и GPT через этот протокол, T3 Code их не увидит.
