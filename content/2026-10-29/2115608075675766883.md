Jake Paterson asks for the Claude and ChatGPT models from Google Antigravity to be added to T3 Code. The first screenshot shows the Antigravity provider in T3 Code settings with only Gemini 4 Argon and Gemini 3.8 Flash. The second shows the Antigravity account quotas, including a shared "Claude & GPT" quota. So the subscription gives access to these models, but T3 Code doesn't have them.

Theo replies that T3 Code exposes what Antigravity provides over ACP, and there's not much they can do about it. ACP (Agent Client Protocol) is an open protocol that editors and other clients use to talk to coding agents. If Antigravity doesn't publish the Claude and GPT models through this protocol, T3 Code won't see them.
